Café Yungas

Tienda online de café boliviano que hice para practicar HTML, CSS y JavaScript. Se pueden ver los productos, filtrarlos por categoría, agregarlos al carrito y mandar el pedido por WhatsApp.

¿Cómo funciona?

Los productos están en un arreglo dentro de `index.html`. El carrito se guarda en `localStorage`, así que no se pierde si recargas la página.
